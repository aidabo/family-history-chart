# 操作ショートカット（キー / マウス / タッチ）

家系図エディタ（`DynastyNetwork` キャンバス）の操作一覧です。実装は
`src/lib/components/canvas/DynastyNetwork.tsx`。

## キーボード

| キー | 動作 | 補足 |
|---|---|---|
| **方向キー ←→↑↓**（ノード選択中） | **選択したノードだけ**を移動 | 横(←→)は Y=年 を変えないので**年表の時間順が崩れない**。ステップ = グリッドON時は grid サイズ／OFF時は 10px。**Shift で4倍** |
| **方向キー ←→↑↓**（選択なし） | **viewport をパン**（連続移動は長押し） | 横は矢印と**逆向き**（→ で viewport 左＝内容が右へ）、縦は**矢印どおり**（↑ で viewport 上）。**Shift で高速**（55→150px） |
| **Esc** | 接続モード解除 ／ 手描きの選択解除 ／ **ノード範囲選択の解除** | 状況に応じて有効なものを解除 |
| **Delete / Backspace** | 選択中の**人物 or 関係**を削除 ／ 手描き「選択」ツール時は**選択ストローク**を削除 | 入力欄フォーカス中は無効 |
| **Ctrl / ⌘ + Z** | 手描き（お絵かき）を**元に戻す** | ノード編集は対象外（手描きのみ） |
| **Ctrl + Shift + Z** / **Ctrl + Y** | 手描きを**やり直し** | |

> 入力欄（INPUT/TEXTAREA/contenteditable）や一部フォーム要素（SELECT/BUTTON）にフォーカスがある間、方向キー等は無効化されます。

## マウス / タッチ

| 操作 | 動作 |
|---|---|
| **空白をドラッグ** | パン（画面移動） |
| **ホイール** / ピンチ | ズーム |
| **空白をダブルクリック** | その位置に**人物を追加** |
| **ノードをダブルクリック / ダブルタップ** | **名前**をインライン編集 |
| **ノードをドラッグ** | そのノードを移動 |
| **Shift + ノードをドラッグ** | **連結ツリー全体（連結成分）を移動** |
| **Ctrl / ⌘ + ノードをクリック** | **接続（関係付け）モード**（次にクリックした相手と関係を張る） |
| ノードにホバー → **青いポートをドラッグ** | 相手ノードへ**関係線を引く** |
| メモ（type:note）をドラッグ / ダブルタップ | 移動 / 本文編集 |

## 範囲選択モード（ツールバー「範囲選択」トグル）

`Shift+ドラッグ`のツリー移動とは別に、**複数ノードを矩形選択して選んだ分だけ**動かせます。

1. キャンバス右上ツールバーの **「範囲選択」** を ON（カーソルが十字に）。
2. **空白をドラッグ**して矩形（マーキー）を描く → 中心が矩形内の人物ノードが選択（青い破線リング）。
3. **選択したノードのどれかをドラッグ** → **選択したノードだけ**を一括移動。**方向キー**でも微移動可（上表参照）。
4. **Esc** で解除。範囲外のノードをドラッグしても解除。OFF で通常のパンに戻る。

## お絵かき（ホワイトボード）ツール

FAB「お絵かき」→ ツールパネル：**ペン / マーカー / 直線 / 矢印 / 矩形 / 楕円 / 消しゴム / 選択・移動**。
色・太さ・戻す/やり直し・全消去。「選択・移動」ツールでは手描きを矩形選択して移動・Delete 削除。
（`Ctrl+Z` / 「戻す」ボタンは手描きの undo/redo。モバイルはボタンで操作）

## シネマ再生（録画向け・全画面）

左上ズームバーの **🎬（フィルム）アイコン** → 設定パネル：
- **モード**：横スクロール（左→右）／縦スクロール（上→下・年表向き）／ズーム（全体→中心）
- **速度（秒）**：5〜60 秒でスイープ時間を調整
- **▶ 全画面で再生**：全画面に入り UI を隠して、なめらかに自動スクロール（`d3.interpolateZoom` によるシネマ的な補間）

再生中は**ボタンを一切表示しません**。キーボードで操作：

| キー | 動作 |
|---|---|
| **Space** | 一時停止 / 再開 |
| **Esc** | 終了（全画面解除・全体表示に戻る） |
