# CSV インポート / エクスポート フォーマット

家系図の**基本情報と関係**だけを、誰でも編集できる **1行＝1人** の CSV で入出力します。
Excel / Google スプレッドシートでそのまま開けます。数百人規模（村・一族）を想定。

- 文字コード：**UTF-8**（BOM 付き可）。区切りはカンマ `,`。
- 1行目は**ヘッダー**（列名）。**日本語・英語どちらの列名でも認識**します。
- インポートは現在の図に**追記（マージ）**します（既存は消えません）。
- 親・配偶者などは**「名前」で相手を参照**して関係を自動生成します（同名が多い場合は `ID` 列を併用）。

## 列（ヘッダー）

| 日本語 | 英語(別名) | 必須 | 説明 |
|---|---|---|---|
| 名前 | name | ✅ | 表示名。関係の参照キー |
| 性別 | gender | — | `男`/`女`/`その他`（`male`/`female`/`other` も可）→ 既定色 |
| 生年 | birth | — | 例 `1534` または `1534-06-23` |
| 没年 | death | — | 例 `1582` |
| 父 | father | — | 実父の名前 → 親子（血縁） |
| 母 | mother | — | 実母の名前 → 親子（血縁） |
| 配偶者 | spouse | — | 配偶者の名前。複数は `；`(全角/半角セミコロン)区切り → **すべて「結婚」**＋ union |
| 養父 | fosterFather | — | 養親の名前 → 親子（ラベル「養子」） |
| 養母 | fosterMother | — | 養親の名前 → 親子（ラベル「養子」） |
| 義父 | stepFather | — | 義理の親の名前 → 親子（ラベル「義理」） |
| 義母 | stepMother | — | 義理の親の名前 → 親子（ラベル「義理」） |
| 肩書 | title | — | 役割・身分（皇帝／丞相／大将軍／軍師 等）。**臣/将/谋士 の別はここで表す**。帝王系譜では **朝代名のみ**（例 `唐`）。在位年は `期間` 列へ |
| 期間 | period (在位/reign) | — | 在位などの期間（例 `626-649` / `前221-前210`）。表示は **肩書(期間)**。**年表の縦軸基準**にも選べる（既定は生没年） |
| 主君 | lord (master/liege) | — | 仕える君主の名前 → **君臣（主従）**関係（君→臣）。複数は `；` 区切り。歴史・物語向け |
| 継承 | succession | — | 前の帝王（先王）の名前 → **継承（succession）**関係（先王→この人物）。複数は `；` 区切り（再即位など） |
| 朝代更换 | custom | — | 前の王朝の最後の君主の名前 → **custom（ラベル「朝代更换」）**。禅让・易代・滅亡など王朝交代。複数は `；` 区切り |
| メモ | note | — | 説明（description） |
| ID | id | — | 同名が多いとき用。指定時は 父/母/配偶者/養父… が **ID でも参照可** |

不要な列は省略できます（`名前` だけでも可）。列の順序は自由（ヘッダー名で判定）。

### 各列が生成するもの（ノード / 関係）

「**ノード**」＝図の丸／箱、「**関係**」＝ノードを結ぶ線。参照される名前が CSV 内に未登場なら、**最小情報でノードを自動作成**してから接続します。

| 列 | 生成する **ノード** | 生成する **関係（エッジ）** | 向き |
|---|---|---|---|
| `名前` / `ID` | 本人＝**人物ノード** | — | — |
| `性別` `生年` `没年` `肩書` `期間` `メモ` `画像` | （本人の**属性**のみ。ノード/関係は作らない） | — | — |
| `父` / `母` | 参照人物（未登場なら自動作成） | **親子**(parent-child) | 親 → 子 |
| `配偶者` | 同上 | **結婚**(marriage)＋union | 双方向 |
| `養父` / `養母` | 同上 | 親子（ラベル「養子」） | 親 → 子 |
| `義父` / `義母` | 同上 | 親子（ラベル「義理」） | 親 → 子 |
| `主君` | 同上 | **君臣**(liege) | 君 → 臣 |
| `継承` | 同上 | **継承**(succession) | 先王 → この人物 |
| `朝代更换` | 同上 | custom「朝代更换」 | 前朝の最後 → 次朝の最初 |
| `師` | 同上 | custom「師」 | 師 → 弟子 |
| `著作` `学派` `事件` `地` `概念` | **非人間エンティティノード**（自動作成） | custom「著作/学派/事件/地/概念」 | 人物 → エンティティ |

> つまり **ノードを増やす列**＝`名前`(本人)・血縁/配偶/参照系(父母配偶者養父…主君継承等の参照先)・エンティティ列。**関係を作る列**＝父母配偶者/養父母/義父母/主君/継承/朝代更换/師/エンティティ列。**属性だけの列**＝性別/生年/没年/肩書/期間/メモ/画像。

## 関係の自動生成ルール

1. **父 / 母** → その行の人物への **親子（parent-child, 血縁）**。両方揃うと **union（補助ノード）** でまとめ、子は union から分岐。
2. **配偶者** → **結婚（marriage）＋ union**。複数指定は**すべて結婚**（再婚扱いにしない）。子は自分の **父＋母** の組み合わせで、対応する結婚（union）にぶら下がる。
3. **養父 / 養母** → 親子（**ラベル「養子」**）。血縁の 父/母 と併記も可。
4. **義父 / 義母** → 親子（**ラベル「義理」**）。
5. **主君** → **君臣（主従, liege）**関係（**君→臣**の向き、紫の矢印線・ラベル「君臣」）。役割（臣/将/谋士）は各人物の **肩書** で表す。血縁とは独立に張れるので、家系図に君臣ネットワークを重ねられる。
6. 参照先の名前が CSV 内に無ければ、**その名前で人物を最小情報で自動作成**してから接続。
7. `(父,母)` など**親の組み合わせごとに union は1つ**だけ作成し、同じ組の子をまとめる。
8. **継承** → **継承（succession）**関係（先王→この人物）。父子・兄弟・叔侄・養子など関係の種別に関わらず「次の王は誰か」を表す。
9. **朝代更换** → **custom** 関係（ラベル「朝代更换」）。王朝の交替（禅让・易代・滅亡）を、前の王朝の最後の君主 → 次の王朝の最初の君主 の順で張る。血縁・継承とは独立。
10. **師** → **custom** 関係（ラベル「師」）。学統・師弟（**師 → 弟子**）を表す。複数可（`；` 区切り）。キャンバスでは**矢印付き**（矢印は弟子側を指す＝反対の端が師）で向きが分かります。
11. **エンティティ列**（著作 / 学派 / 事件 / 地 / 概念）→ 各値を **「非人間エンティティ」ノードとして自動作成**し、人物 → エンティティ の **custom** 関係を張る。複数可（`；` 区切り）、共有（共著・同学派など）は複数人物から同一ノードに接続。

### 非人間エンティティ（`entity`）

「人物ではない関連物（著作・学派・事件・地・概念…）」を **ノード＋関係** で表現します。人物 ─[関係]→ エンティティ の形。

| 列（日本語 / エイリアス） | `entity` 種別 | 関係ラベル | 既定色 | 例 |
|---|---|---|---|---|
| `著作` / 作品 / works | `work` | 著作 | 琥珀 | 《論語》 |
| `学派` / 流派 / 組織 / 所属 / school / org | `org` | 学派 | 緑 | 儒家 |
| `事件` / 出来事 / event | `event` | 事件 | 橙 | 焚書坑儒 |
| `地` / 地名 / 場所 / place | `place` | 地 | ティール | 稷下学宮 |
| `概念` / 思想 / concept | `concept` | 概念 | 紫 | 陰陽五行 |

**共通の挙動：**
- 人物とは**別色**で表示、**性別・生没年を持たない**（編集ダイアログでもこれらの欄は非表示）。
- **登場人物カウントに含めない**。
- 年表では年を持たないため、**つながっている人物（年あり）の近く**に配置。
- **エクスポート時は独立行になりません** — 人物行の該当列に出力（列は人物側に属する。再インポートでノードと関係が復元）。
- エッジラベルは **ロケール対応（ja / zh / en）**：著作→Works、学派→School、事件→Event、地→Place、概念→Concept、師→Teacher。
- **後方互換**：`entity` 未設定＝従来の人物。既存データは不変。

**サンプル（著作・学派・事件・地・概念）：**
```csv
名前,性別,生年,没年,肩書,師,学派,著作,事件,地,概念,メモ
孔子,男,前551,前479,儒家の祖,,儒家,《論語》,,魯国,仁；礼,春秋の思想家
孟子,男,前372,前289,亜聖,孔子,儒家,《孟子》,,鄒国,性善説,孔子の学統
荀子,男,前313,前238,,,儒家,《荀子》,稷下の学,斉国,性悪説,
```
→ `儒家`(学派/org)・`《論語》`(著作/work)・`稷下の学`(事件/event)・`魯国`(地/place)・`仁`/`礼`(概念/concept) がそれぞれノード化し、各人物と**色分けエッジ**で接続。`儒家` は3人が共有＝1ノードに集約。英語列名でも可（例 `school,works,event,place,concept`）。

> 人物は **常に1人1行**。再婚しても行は増えず、`配偶者` 列に `；` で追記するだけ。
> 「どの結婚の子か」は子ども行の **父・母** で判別します。

## サンプル

### 1. 基本（親子と結婚）
```csv
名前,性別,生年,没年,父,母,配偶者,肩書
織田信秀,男,1511,1551,,,土田御前,
土田御前,女,,,,,織田信秀,
織田信長,男,1534,1582,織田信秀,土田御前,濃姫,第六天魔王
濃姫,女,1535,,斎藤道三,,織田信長,
織田信忠,男,1557,1582,織田信長,濃姫,,
```

### 2. 複数の結婚（すべて結婚）と、妻ごとの子
```csv
名前,性別,生年,没年,父,母,配偶者
豊臣秀吉,男,1537,1598,,,寧々；淀殿
寧々,女,,,,,豊臣秀吉
淀殿,女,1569,1615,浅井長政,,豊臣秀吉
豊臣秀頼,男,1593,1615,豊臣秀吉,淀殿,
```
- 秀吉＝1行、配偶者2人（`寧々；淀殿`）→ 結婚が2つ。
- 秀頼は 父=秀吉・母=淀殿 → **秀吉×淀殿** の union に接続（寧々側ではない）。

### 3. 養子（養父・養母）
```csv
名前,性別,生年,没年,父,母,養父,養母,配偶者
豊臣秀吉,男,1537,1598,,,,,寧々
豊臣秀次,男,1568,1595,三好吉房,とも,豊臣秀吉,寧々,
```
- 秀次は実親（三好吉房・とも）＝親子（血縁）、かつ **養父=秀吉・養母=寧々** → 親子（ラベル「養子」）。

### 4. 義理の子（義父・義母）＝連れ子・再婚相手の子
```csv
名前,性別,生年,没年,父,母,義父,配偶者
前夫,男,,,,,,先妻
先妻,女,,,,,,前夫；新夫
新夫,男,,,,,,先妻
連れ子,男,,,前夫,先妻,新夫,
```
- 連れ子は実親（前夫・先妻）＝血縁の親子、かつ **義父=新夫** → 親子（ラベル「義理」）。
- 先妻は `前夫；新夫` の2結婚。

### 5. 大人数（村・一族）
同じ列のまま行を増やすだけ。親・配偶者は名前で参照するので、**行の順序は不問**（後方参照OK、未登場の名前は自動作成）。

```csv
名前,性別,生年,父,母,配偶者
祖父,男,1900,,,祖母
祖母,女,1905,,,祖父
父,男,1930,祖父,祖母,母
母,女,1933,,,父
本人,男,1960,父,母,妻
妻,女,1962,,,本人
長男,男,1990,本人,妻,
長女,女,1992,本人,妻,
```

### 6. 君臣（主君）＝ 歴史・物語の君主と臣下・将・軍師
`主君` 列で仕える君主を指し、役割は `肩書` で表します（血縁とは独立）。

```csv
名前,性別,肩書,主君,メモ
劉邦,男,皇帝,,漢の高祖（君）
蕭何,男,丞相,劉邦,臣（文官）
韓信,男,大将軍,劉邦,将
張良,男,軍師,劉邦,谋士
```
- 劉邦→蕭何／韓信／張良 に **君臣（紫の矢印・ラベル「君臣」）** が張られる。臣/将/谋士 の別は肩書で判別。
- 配偶者・父母 列と併用すれば、**家系図＋君臣ネットワーク**を1枚に重ねられる。

### 7. 帝王系譜（継承＋朝代更换）＝ 中国歴代帝王

1行＝1帝王。**肩書＝朝代名**・**期間列＝在位年**（例 `唐` / `626-649`。表示は「唐 (626-649)」）。同朝代内の先王→後継は **`継承` 列**、王朝交代（禅让・易代・滅亡）は **`朝代更换` 列**で表します。

```csv
名前,肩書,期間,継承,朝代更换,メモ
秦始皇帝嬴政,秦,前246-前210,,
秦二世胡亥,秦,前210-前207,秦始皇帝嬴政,,
秦王子嬰,秦,前207,秦二世胡亥,,
漢高祖劉邦,前漢,前202-前195,,秦王子嬰,秦滅→漢
漢惠帝劉盈,前漢,前195-前188,漢高祖劉邦,,
漢文帝劉恆,前漢,前180-前157,後少帝劉弘,,兄終弟及
魏文帝曹丕,魏,220-226,,漢獻帝劉協,禅让
晉武帝司馬炎,西晉,265-290,,魏元帝曹奐,禅让
隋文帝楊堅,隋,581-604,,北周靜帝宇文闡;陳後主陳叔寶,禅让・陳滅
唐太宗李世民,唐,626-649,唐高祖李淵,,
```

- 先王が複数いる場合（再即位・複数系統から受け継ぐ場合）は `；` 区切り（例：隋文帝は北周から禅让・陳を滅ぼした2つを列挙）。
- 続けて読み取れば、1本の「中国歴代王朝の帝位継承ライン」になります。

## 補足

- **重複名**：同じ名前が複数いる場合は `ID` 列を付け、父/母/配偶者/養父… で ID を参照してください。
- **日付**：年だけ（`1582`）でも、`YYYY-MM-DD` でも可。文字列としてそのまま保持します。
- **区切り記号**：配偶者・複数親の区切りは `；`（全角）/ `;`（半角）どちらも可。
- **任意の乱雑な CSV**（列名がバラバラ・自由形式）を取り込みたい場合は、将来的に AI による列マッピング支援を追加できます（本フォーマットは AI 不要で直接パース）。
